🔬 실제 기상청 레이더 관측자료와 본 교육용 시뮬레이터의 차이

본 프로그램은 기상학 및 물리학 교육 목적의 시뮬레이터입니다. 실제 기상청(KMA) 기상 레이더 관측망의 원시 신호 처리 자료와 본 시뮬레이터의 데이터 생성 방식을 아래와 같이 명확히 구분하여 이해해야 합니다.

구분 항목 실제 기상청(KMA) 도플러 기상 레이더 본 교육용 도플러 레이더 시뮬레이터
강수 분포 데이터 출처 관악산·백령도·광덕산 등 전국 레이더 사이트에서 수평·수직 편파 전파를 발사하여 직접 수신한 3차원 볼륨 반사도(dBZ) 관측자료 기상청 단기예보/초단기실황 API(또는 데모 데이터)의 강수량·강수확률·풍향·풍속을 초기 조건으로 생성한 모의 강수 분포
강수확률(POP)의 의미 레이더는 강수확률을 측정하지 않으며, 대기 중 수상체(빗방울·눈송이)의 크기와 수밀도에 비례하는 반사도 인자(Z)를 관측함 예보의 강수확률과 강수량을 시각적 에코 크기 및 입자 밀도 설정에 참고하되, 물리적 반사도와 동일한 물리량이 아님을 명시함
도플러 속도 계산 방식 수천 개의 펄스 쌍(Pulse-Pair) 간 위상차(Δφ)와 스펙트럼 모멘트를 고속 푸리에 변환(FFT)으로 통계 처리하여 시선속도 산출 사용자가 설정하거나 기상 데이터에서 연동된 입자 속도(v)와 시선각(α)에 대해 물리 공식 λ = c/f₀, Δf = 2vr/λ를 엄밀히 적용하여 실시간 계산
관측 범위 및 한계 요소 지구 곡률에 따른 빔 고도 상승, 지형 클러터(산악 반사), 밝은 띠(융해층), 나이퀴스트 속도 접힘(Velocity Folding) 현상 존재 도플러 효과와 시선속도 벡터 분해(vr = v·cos α)의 순수 물리 원리를 직관적으로 관찰할 수 있도록 이상화된 2차원 평면으로 구현
실제 기상 레이더 관측 영상 확인 안내: 실제 기상청 레이더 합성 영상(전국 강수 에코 및 바람 벡터)은 기상청 날씨누리(weather.go.kr) 또는 공공데이터포털의 「기상청_레이더 영상 조회서비스」에서 별도의 레이더 이미지 API를 통해 열람할 수 있습니다.

📍 위치정보 사용 동의 및 관측 기준 지역 설정

현재 위치 기반의 실시간 기상정보(기온, 풍향, 풍속, 강수 형태 등)를 불러와 도플러 기상 레이더 시뮬레이션의 초기 조건으로 활용합니다.

🔒 개인정보 보호 원칙: 브라우저에서 확인된 위·경도는 기상청 격자 좌표(NX, NY) 변환 및 기상 조회에만 사용되며, 화면에는 상세 주소 없이 시·군·구 단위만 표시됩니다.

🔑 기상청(KMA) 공식 단기예보 API 인증키 설정

실제 기상청 관측(초단기실황) 및 예보(단기예보) 데이터를 연동하려면 공공데이터포털에서 발급받은 본인의 인증키가 필요합니다. 본 프로그램에는 임의의 가짜 인증키가 포함되어 있지 않습니다.

공공데이터포털 API 발급 및 설정 방법:
  • 1. 공공데이터포털(data.go.kr) 회원가입 및 로그인
  • 2. 「기상청_단기예보 ((구)_동네예보) 조회서비스」 활용신청 (자동승인)
  • 3. 마이페이지 → 인증키 발급현황에서 일반 인증키(Encoding 또는 Decoding) 복사
  • 4. 아래 입력창에 붙여넣고 저장 (브라우저 로컬 저장소에만 보관됨)
  • ※ 주의: 로컬 파일(file://) 환경에서 브라우저 보안(CORS) 정책으로 외부 API 호출이 차단될 경우 자동으로 안전하게 데모 모드로 전환됩니다.
